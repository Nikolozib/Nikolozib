## What I'm working on

I'm focused on the gap between "it works" and "it holds up" — clean architecture in .NET, advanced Angular patterns (standalone components, signals), and UI/UX that doesn't feel like an afterthought.

**Currently learning:** clean architecture & CQRS in .NET · advanced Angular patterns · modern UI/UX practice

**Open to collaborating on:** web apps, APIs, dashboards, and startup or open-source projects that have real users

**Happy to talk about:** Angular, REST API design, C#, Entity Framework, SQL Server — and turning a half-formed idea into something shipped

**Could use a hand with:** system design, performance optimization, and scaling applications past the prototype stage
